My Word Repeater C Program

Here is the C code for my program that repeats a word a specified number of times.


#include <stdio.h>

int main() {
    char word[200];
    int num_repetitions;

    printf("Enter a word: ");
    fgets(word, sizeof(word), stdin);

    printf("Enter the number of times to repeat: ");
    scanf("%d", &num_repetitions);

    for (int i = 0; i < num_repetitions; i++) {
        printf("%s\n", word);
    }

    return 0;
}
